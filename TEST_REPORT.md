## What was checked

The 11 archived nested-pipeline tests cover synthetic holdout and inner-validation
perturbations, training-fold preprocessing and feature-selection boundaries,
missingness rules, subtype exclusion from splitting, the 49-feature/113-candidate
specification, LASSO API equivalence, and checkpoint/resume integrity. Their
historical-specification test reads the mirrored Legacy Q3 Python file through
its abstract syntax tree; it does not import or execute the Legacy Q3 workflow.
The remaining tests use arrays generated by their local random-number generator
or temporary artificial files, not a clinical input CSV.

The seven archived training-event tests use constructed dictionaries and log
strings. They test disjoint warning-count buckets, selected versus unselected
candidate accounting, absent OOF warning records as unknown rather than zero,
parameter consistency, all-feature placeholders, invalid counts, and duplicate
log handling. They do not read saved clinical warnings or patient records.

The 12 new tool tests check literal-only source inspection, deterministic
artificial inputs, invalid fixture sizes, a non-executing default help command,
rejection of an arbitrary `--raw` argument, a check-only path that launches no
subprocess, temporary-only subprocess arguments, success/failure cleanup,
suppression of captured subprocess logs, complete artificial checkpoints,
rejection of publication-eligible output, and detection of prediction or file
tampering. Subprocess calls inside these unit tests are mocked; the separate
`--run` command above performed the actual reduced pipeline execution.

The ten added precision tests use generated rank-score arrays and constructed
fixtures. They compare tied ranks with SciPy's Spearman implementation, explicit
leave-one-split-out deletion, the paired contrast, and invariance under row
permutation; they also check rank reversal, constant and near-degenerate cases,
invalid inputs, and compatibility with the manuscript's `result@` macro
namespace. They do not open the retained aggregate files. The separate
aggregate-only precision calculation is not a synthetic test or a rerun of the
patient-based models, and its generated outputs are not distributed here.

The helper generated **240 artificial rows with exactly 52 columns**, comprising
the 49 input features plus the score and two blood-count formula inputs. Every
value was generated by the helper's local PRNG or explicit artificial fixture
rules; no patient value or fitted clinical distribution was consulted. The
fixture deliberately supplies a strong artificial age signal to keep the small
LASSO software test nonempty. It is not a clinically realistic dataset or a
performance benchmark.

For the actual smoke command, the unchanged archived pipeline ran with
`--mode smoke --splits 1 --workers 1 --split-workers 1`. No historical parameter
file, primary-analysis mode, or OOF option was supplied. The helper verified:

- completed run and checkpoint status for exactly one split;
- `mode=smoke` and `publication_eligible=false`;
- required output files and their checkpoint SHA-256 hashes;
- complete, unique artificial source-row membership and fixture-consistent
  outcome labels;
- the expected 75%/25% partition and complete held-out prediction coverage for
  all eight retuned model groups;
- finite prediction scores, probability bounds, and unchanged analysis-source
  SHA-256.

All generated CSVs and outputs were created in a `TemporaryDirectory` and were
removed when the checks finished. No synthetic checkpoint or prediction file is
retained in, or intended for distribution with, this repository. The original
clinical data and result directories were not used or modified.

## Limits of the evidence

- Passing these checks supports the tested software interfaces and invariants,
  not the accuracy, validity, or reproducibility of the reported clinical
  estimates or conclusions.
- No real patient data, historical clinical predictions, fitted clinical models,
  or clinical checkpoints were loaded. The full clinical grid, 200-split clinical
  analyses, and original 400-dataset simulation were not rerun.
- Reduced smoke mode is intentionally not publication evidence. Its runtime and
  artificial predictions must not be reported as study performance.
- This is an AI-assisted test record of observed commands and outcomes, not an
  author approval, external replication, security certification, or assertion
  that the entire repository is runnable without its excluded inputs.
